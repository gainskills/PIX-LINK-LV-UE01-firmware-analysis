# PHY 诊断补丁离线可行性结论

后续实现更新：独立离线诊断候选现已实现，10 项机器码/封装测试通过，压缩体 656,021 字节，余量 52,743 字节；详见 [诊断候选](../phy-diagnostic/README.md)。尚未刷写或实机验证。以下保留原 feasibility spike 的历史范围和结论。

结论：**核心 PHY 读取和补丁放置在离线层面可行；完整诊断固件尚未实现，不能刷机。**

本次是用户已批准的 feasibility spike，输出为判断和证据。临时原型、模拟器依赖仅位于 `/private/tmp/lvue01-phy-spike`，标记 THROWAWAY，不是产品实现。本轮没有生成、刷写或上传诊断固件。

## 已完成的验证

- 生成 224 字节的 MIPS32 little-endian 只读 PHY 查询原型，执行模拟的 MDIO read 事务；不调用原先无界等待的 helper。
- 参数限制在 PHY 0–4、标准寄存器 0–6。先检查控制器忙状态，保存中断/引脚状态，在临界区执行一次查询；成功、忙或超时都返回。超时上限为 65,536 次轮询，尚无实机墙钟时间标定。
- 使用 Unicorn 2.1.4 执行机器码，12 个场景均通过：立即完成、延迟完成、进入时中断关闭、进入时引脚已为 MDIO、超时清理、读忙、写忙、PHY 越界、寄存器越界、最大允许参数、正常内核模式成功及其超时。
- 模型断言：MMIO 访问期间 IE 关闭；仅写 GPIO 模式和 MDIO read 命令，不向 PHY 发配置 write；退出恢复完整保存的 CP0 Status 和 GPIO 模式。忙/参数无效路径不写硬件；超时路径在指定轮询次数后返回。
- 只读检查既有 CLI reg callback 指针（0x802123f0 → 0x80112960）和主动 relink 函数入口原始指令，确认存在可审查的后续插入点；没有实际修改这些指针或指令。
- 现有新网页候选已退役图片区域有 41,127 字节零空间。将原型仅放入内存中的副本后压缩，压缩体 655,556 字节、预算 708,764、余量 53,208 字节；解压逐字节回读一致，解压后总长不变。尚未包含 CLI 包装及事件记录，不是完整补丁尺寸。
- 既有候选 SHA256 前后均为 `75581dd659ed625e7547ce91b89803f0983df49b7a537c0ebb7e1302bdf1178f`，没有重写它。

机器可读证据：`diagnostic-spike-emulation.json`、`diagnostic-spike-placement.json`。

## 尚未证明的事项

模拟 MMIO 不代表真实芯片时序、硬件并发、缓存执行或整机可启动。超时后恢复中断/引脚不等于 MDIO 控制器一定恢复，也不证明后续原生驱动访问不会遇到异常。读取 BMSR 可能清除锁存状态，后续完整诊断必须保留第一次与第二次读值并说明其含义。

本次没有实现 CLI 参数分发/日志输出，也没有 relink 计数或时间记录的集成与验证。既有原生行为、callback ABI、格式化输出、重连时序均需在完整候选中另行校验。当前仍未确定 X99 故障根因，原型不能作为修复。

## 推荐的后续小范围实现

独立的离线诊断候选：通过受限 CLI 子命令读取 PHY 0 控制、BMSR 两次、协商通告和对端能力；查询完成后再输出日志。增加主动 relink 调用计数/时间记录，用于区分固件主动操作与链路自身掉线。现有 reg 命令的原有分发保持兼容，不自动轮询，不改协商、EEE、功率或网络配置。

这是后续实现建议，不是本次已完成的产品补丁。先完成候选的机器码/ABI/异常路径/容器大小验证，再考虑完整 2 MiB 备份和恢复准备。当前只有 1 MiB 已导出文件，不具备已验证的完整恢复。
