## 离线锚点

- `cli-arp-disassembly.txt`：CLI 分发和 ARP 警告格式。
- `driver-stat-disassembly.txt`：统计格式化路径；Tx success 对应 0x8003d7e8，Tx fail 对应 0x8003dfc8，Rx success 对应 0x8003d914，Rx CRC 对应 0x8003d988。计数来自无线 adapter 结构，不是从 X99 的流量过滤得到。
- ARP receive 0x80051a4c 从 ARP target IP 读取值并调用 0x80051950 的 IP→MAC 查询，随后复制目标硬件地址；查询成功会刷新条目时间。哈希未命中时走表内默认条目，不可仅由静态代码认定实际发生误转发。
- 终端此前的警告字符串为 `arp: %6p is using my IP address %s!`，0x8019ab00；它来自另一条 ARP 栈路径，不能直接等同于 MAT 查询出错。
