## 交换配置解读与限制

使用本地保留的 `esw_rt3050-upstream.c` 的位定义解读，尚无完全匹配的厂商 SDK：

- POC0=0x10007f7f：禁用掩码为 0x20，即 port5；port0 未禁用。
- SOCPC=0x02404040：unknown-unicast/multicast/broadcast 禁用掩码均为 0x40，port0 位未置位。此配置没有直接阻断 port0 的广播转发。
- PVID01=0x2002：port0 默认 VID=2；VLANI01=0x2001、VMSC03=0x5f40，VID2 的成员掩码为 0x5f，包含 port0 和 CPU port6。未见该成员配置将 port0 与 CPU 分离。
- PFC1=0x00401555、POC2=0x7f3f、SGC2=0，前后不变。
- 参考驱动 `esw_get_port_recv_badgood` 读取 0xe8+4*port，低/高 16 位为 good/bad；`esw_get_port_tr_badgood` 对包含 MT7628AN 的分支读取 0x150+4*port。按此解释 RX good/bad 均零，TX good=33663/bad=0。目标是 MT7628KN，计数器映射、门控、回绕和复位语义仍需实机对照，不能将零值直接称为芯片接收故障。
