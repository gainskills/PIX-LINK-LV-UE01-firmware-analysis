**2026-10-21已完成本机授权实验升级。** 包含本界面及后端认证修补的当前安全候选已运行，新页面/读取保护和配置保留检查通过，见[实际升级记录](../deployment/README.md)。本目录原网页候选保留不覆盖，以下构建与历史浏览器结果仍指该基线；X99/mDNS长期观察独立进行。

后续开发入口：[新版固件主线](FIRMWARE-WORK.md)。X99 稳定性验证单独长期进行，不阻塞界面和后端安全工作；下一项为原 HTTP 后端的认证保护。

预览入口：http://127.0.0.1:8765/index.htm 。`/`、`/index.htm` 和 `/lan.htm` 都显示新控制台。预览只使用模拟配置；模拟的 MAC、状态、密码和固件版本不代表实时设备读数。

## 新界面功能

- 无线状态精简为模式、无线客户端数量、固件版本、运行时间和设备 MAC。移除重复的 Wi-Fi 已启用、连接目标和安全配置。实时连接状态移至“上游 Wi-Fi”，实时信道移至“无线电设置”；均从原状态响应读取，无法读取时显示“暂不可用”，不以保存配置冒充实时值。通过刷新按钮读取，不自动扫描或轮询。
- 客户端数量明确标为“无线客户端数量”，不包含 X99 等以太网设备。固件有 PHY link up/down 代码与 MAC 学习表，但尚未恢复供新页面读取有线连接状态的接口；本轮没有伪造以太网设备数量。
- DHCP 服务器控制移入 Wi-Fi 设置，仅在 AP 模式可操作；中继模式禁用并保持关闭。
- 管理地址区域直接显示可选静态地址和上游管理端口，移除 Advanced settings 嵌套层与“通过上游 IP 管理”开关。普通保存、连接上游与备份恢复保持 SYS_RM_EN=1；静态地址为附加入口，启用它不关闭上游入口。旧配置关闭上游且端口无效或与静态端口 80 冲突时，建议值回退为 8080；仍拒绝修改当前正在使用的管理端口。未保存前不自动写入。
- AP / 中继模式切换；中继模式保存时保持本机 DHCP **服务器**关闭，上游 DHCP **客户端**不受该开关控制。切换到新上游时需主动扫描并选择网络以确定信道，然后填写上游密码。扫描仅在用户点击并确认时触发。
- 可编辑本机 Wi-Fi / 扩展 SSID。默认规则为 `<上游SSID>_<设备MAC>`，MAC 使用本机状态中的网络接口地址，移除分隔符并转为 12 位大写十六进制；不使用上游 BSSID、不硬编码某台设备的 MAC。
- SSID 按 UTF-8 **字节**校验为 1–32 字节。默认名称保留 `_` + 完整 12 位 MAC，按 Unicode 码点截短上游前缀至最多 19 字节。例：`TEST-UPLINK_020000000001`。
- 旧的自动名称（恰好等于上游 SSID + `_Ext` / `_EXT`）及空名称在取得本机 MAC 后，会在表单中换成新默认名称；仅“保存并重启”后写入设备。自定义名称保持原样；手动编辑后停止自动跟随，点击“使用默认名称”可恢复默认生成行为。MAC 不可用时保留名称并禁用默认名按钮，允许手动编辑。
- 本机 SSID、隐藏 SSID、WPS 和密码归入“本机 Wi-Fi”，共享无线参数归入“无线电设置”，并与“上游 Wi-Fi”分区。保留“隐藏 SSID”。**移除无线电总开关**：该单无线电设备在中继模式下依赖同一无线电连接上游，关闭它会切断回程，并可能让有线终端无法取得 DHCP 地址。普通保存保留 WLN_RadioOn，配置恢复拒绝关闭无线电。
- “本机 Wi-Fi”位于“上游 Wi-Fi”之前，分别使用有边框的区域。新本机密码供连接本机 AP / 扩展网络的终端使用，不是上游路由器密码；密码框留空保留原值。本机和上游分别提供开放网络、WEP、WPA-PSK、WPA2-PSK 和 WPA/WPA2-PSK，以及 AES / TKIP / TKIP-AES 选项。读取实际保存的安全类型和加密方式，编辑密钥不再强制改为 WPA2/AES。本机只修改 BSS1，保留其他 BSS 和上游密钥；WEP 保留原认证模式，输入新密钥时写入 Key 1 并选择对应密钥索引。切换安全类型时需提供兼容密钥，不向表单预填已保存密钥。
- 上游 Wi-Fi 默认展开，可直接扫描、选择网络及更换安全密钥；扫描结果支持固件已有的开放、WEP、WPA/WPA2 与 AES/TKIP 组合，未知/企业认证结果不可选择。扫描仅由用户主动触发。
- SSID 输入框自动换行并随内容增高，完整显示最长 32 字节名称；禁止手动插入换行，保存仍拒绝控制字符。桌面使用统一输入列，手机标签与输入分行；安全类型、加密方式与密钥框宽度和右边缘一致。
- 发射功率 1–100%，不标为 dBm；这是共享无线电参数，可能影响上游连接。带宽提供 20 MHz / 20–40 MHz 配置；中继实际带宽仍取决于上游和驱动协商，不把请求值冒充实际值。
- AP 模式提供自动/手动信道，选项基于已有地区配置；中继不显示可编辑信道，仅显示状态读取的当前信道及单无线电共用上游信道的说明。选择扫描结果时保存该上游的信道及扩展信道方向；上游自动换信道后的重连行为仍依赖原驱动，未声称已真机验证。
- 上游 Wi-Fi 提供“连接并重启”：校验所选网络和密钥，确认后仅保存上游配置、启用中继及关闭 DHCP 服务器，不提交其他未保存的本机 Wi-Fi 或管理设置；重启回读后这些未保存编辑会丢弃，按钮说明与确认框均明确提示。若需一并应用，使用底部“保存并重启”。新网络需扫描选择，原网络可保留兼容密钥；导入回读不一致不重启。管理连接恢复仅表示管理可达，提示检查实际连接状态，不等同于上游连接成功。
- 当前管理地址包含实际访问端口，支持点击和收藏。静态 LAN 管理使用端口 80；上游管理默认 8080，两者分开说明。未启用静态地址时，192.168.10.1 仅为灰色示例；已保存静态地址显示独立的 `http://.../` 链接。
- 管理员用户名和密码、退出登录与新登录页；使用原固件已有的 `Authorization=Basic ...` cookie 协议。密码不预填进界面，不写入日志。账户变更和含新凭据的备份恢复会在回读前更新当前会话凭据；导入失败则恢复原凭据，不请求重启。
- 配置备份、重新读取配置、备份恢复、独立重启按钮。备份下载原始配置，含密码，需妥善保存。恢复校验格式、重复键、无线参数和管理地址，拒绝曾导致失联的 LAN_IP_MODE=0 路径，以及改变当前管理入口的备份。
- 固件上传入口使用原 `SYS_UPG` / `files` 协议。上传前要求确认硬件匹配，并检查 uImage 魔数、尺寸和两项 CRC。上限 718108 字节取自已知原容器，不能据此推断未知 Flash 容量。拒绝文件名带 NOT-FOR-FLASHING / EXPERIMENTAL 标记的候选。**CRC 正确不能证明板型兼容，上传响应也不当作升级成功**；上传后需重新连接并核对版本，真机升级格式和恢复流程仍未验证。
- 页面标题为“Wi-Fi 管理 / Wi-Fi management”，顶部不重复显示模式；状态区显示当前模式，Wi-Fi 设置中提供模式选择。语言、重启设备和退出按钮归入响应式页头操作区，重启紧邻退出之前；底部不再重复显示重启。重启需确认，读取配置前及其他操作进行时禁用。导航行仅保留链接。
- 浏览器首选 zh 系列默认简体中文，其他语言默认 English；支持手动切换，保留未保存输入及当前提示。
- 已审阅并精简中英文说明：DHCP 提示仅说明终端地址分配，管理区域明确 AP/中继模式均可管理且不受 DHCP 服务器开关影响；静态地址和上游地址分别说明用途。删除正常状态下的数据来源说明，无线客户端提示仅为“不统计有线设备”，不再出现特定设备名称。连接、密钥、功率、带宽、备份与升级提示均缩短，保留操作范围和关键限制。词条合并为单一字典，移除被覆盖的旧说明。

## 保存协议与失败处理

配置修改使用已经在原设备验证过的 `SYS_CONF` / `CCMD=3` multipart 导入，文件字段为 `files`。提交前再次读取配置，阻止并发页面覆盖；逐键替换，拒绝缺失/重复键，保留未修改密码、其他 BSS 和未知字段。导入后逐项回读，确认一致后才请求正常重启，并等待当前管理地址恢复。HTTP 200 不单独代表导入成功。更改模式、SSID、密码等操作需要界面中的明确确认。

AP/中继切换、功率/带宽配置、账户更新和完整维护流程目前通过模拟接口验证，尚未在真机验证其运行效果、上游重连或持久性。现有管理入口保护降低失联风险，但不能取代真机恢复验证。
